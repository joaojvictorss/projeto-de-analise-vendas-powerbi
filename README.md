# 📊 Dashboard de Análise de Vendas (Superstore E-commerce)

Projeto prático desenvolvido para portfólio de **Análise de Dados**, simulando o acompanhamento de KPIs comerciais de uma rede de varejo global.

---

## Tecnologias e Ferramentas Utilizadas
* **MySQL:** Limpeza de dados (ETL), conversão de formatos e consultas analíticas avançadas.
* **Power BI:** Modelagem de dados, criação de medidas e construção do Dashboard interativo.

---

##  Estrutura do Repositório
* `queries_analise.sql`: Script contendo a criação da base de dados, tratamento de datas e extração de métricas de negócio.
* `Dashboard_Vendas_Superstore.pbix`: O arquivo fonte contendo o painel interativo desenvolvido no Power BI.

---

##  Principais Indicadores e Insights do Dashboard
1. **Faturamento Total:** Acompanhamento da receita bruta consolidada.
2. **Sazonalidade:** Gráfico temporal mapeando os meses de picos e quedas nas vendas.
3. **Top Categorias:** Identificação das linhas de produtos que geram maior rentabilidade para o negócio.
